# Contributing to ICT Scanner

1. Create a branch for the phase you are working on (e.g., `feat/phase-03-data-streams`).
2. Implement your changes inside `src/ict_scanner`.
3. Write tests in `tests/`.
4. Run `make lint type test` locally to ensure quality.
5. Use Conventional Commits (`feat:`, `fix:`, `docs:`, etc.).
6. Update `CHANGELOG.md` when behavior changes.
7. Push and open a PR to `main`.
